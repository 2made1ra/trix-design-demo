# TRIX — варианты дизайна

Демо-сайт для команды: хаб с пятью вариантами дизайна TRIX и 40 страниц макетов (по 8 на вариант),
собранных из холста «TRIX — сравнение дизайн-систем».

## Команды

- `npm install` — зависимости (React нужен только страницам Sunset Glow).
- `npm run build` — собрать сайт в `dist/`.
- `npm run dev` — собрать и раздать `dist/` на http://localhost:4173.

## Устройство

- `boards/` — файлы макетов как на холсте: `*.dc.html`, общие стили и скрипты эффектов, компоненты
  Sunset Glow в `boards/ds/`. Их не правим руками: обновляем копией с холста.
- `scripts/catalog.mjs` — варианты, страницы, порядок сценария и адреса (`/stripe/home`).
- `scripts/build.mjs` — превращает каждый макет в обычную страницу: ссылки между макетами
  становятся адресами сайта, файлы холста (`/_blob/…`) берутся из `public/blob/`.
- `scripts/hub.mjs` — хаб, таблица сравнения, справка и страница 404.
- `runtime/dc-lite.js` — небольшой рантайм формата макетов: шаблон, `{{…}}`, класс `Component`,
  компоненты дизайн-систем через `<x-import>` и Tweaks из `data-props`.
- `runtime/bar.js` — панель просмотра поверх макета: хаб, переходы, настройки, горячие клавиши.

## Обновить макеты с холста

1. Скачать свежие файлы `project/*` с холста в `boards/`, а новые картинки — в `public/blob/`
   с именем как в ссылке `/_blob/<id>` и расширением.
2. Новую страницу или вариант добавить в `scripts/catalog.mjs`.
3. `npm run build`: сборка упадёт с понятной ошибкой, если ссылка ведёт на страницу без адреса
   или не хватает картинки.

## Деплой на Vercel

Проект статический, настройки в `vercel.json`: Vercel сам выполнит `npm ci` и `npm run build` и
раздаст `dist/` с адресами без `.html`.

1. Запушить репозиторий на GitHub.
2. В Vercel: Add New → Project → импортировать репозиторий, Framework Preset — Other. Остальное
   подтянется из `vercel.json`.
3. Каждый пуш в основную ветку обновляет сайт, остальные ветки получают preview-ссылки.
