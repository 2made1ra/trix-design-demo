# TRIX — Франкенштейн

Демо-сайт для команды: дизайн TRIX «Франкенштейн» — хаб и 8 страниц сценария, собранных из холста
«TRIX — сравнение дизайн-систем», со всеми Tweaks холста.

## Команды

- `npm install` — зависимости.
- `npm run build` — собрать сайт в `dist/`.
- `npm run dev` — собрать и раздать `dist/` на http://localhost:4173.

## Устройство

- `boards/` — файлы макетов как на холсте: `fr-*.dc.html`, общие стили и скрипты эффектов. Их не правим
  руками: обновляем копией с холста.
- `scripts/catalog.mjs` — страницы, порядок сценария, адреса (`/home`) и правило общих Tweaks.
- `scripts/build.mjs` — превращает каждый макет в обычную страницу: ссылки между макетами
  становятся адресами сайта, файлы холста (`/_blob/…`) берутся из `public/blob/`.
- `scripts/hub.mjs` — хаб, справка и страница 404.
- `runtime/dc-lite.js` — небольшой рантайм формата макетов: шаблон, `{{…}}`, класс `Component` и Tweaks
  из `data-props`. Значения по умолчанию — те, что стоят на холсте.
- `runtime/bar.js` — панель просмотра поверх макета: хаб, переходы, боковая панель Tweaks, горячие клавиши.

Tweaks главной из разделов «… — для всех страниц» (палитра, футер, Verge Glow) показываются на каждой
странице и меняются сразу на всём сайте.

## Обновить макеты с холста

1. Скачать свежие файлы `project/fr-*`, `fr.css`, `fr-fx.js`, `verge.css`, `verge-fx.js`, `cursor-fx.js`
   и `trail.js` с холста в `boards/`, а новые картинки — в `public/blob/` с именем как в ссылке
   `/_blob/<id>` и расширением.
2. Новую страницу добавить в `scripts/catalog.mjs`, подпись нового Tweak — в `LABELS` в `runtime/bar.js`.
3. `npm run build`: сборка упадёт с понятной ошибкой, если ссылка ведёт на страницу без адреса
   или не хватает картинки.

## Деплой на Vercel

Проект статический, настройки в `vercel.json`: Vercel сам выполнит `npm ci` и `npm run build` и
раздаст `dist/` с адресами без `.html`.

1. Запушить репозиторий на GitHub.
2. В Vercel: Add New → Project → импортировать репозиторий, Framework Preset — Other. Остальное
   подтянется из `vercel.json`.
3. Каждый пуш в основную ветку обновляет сайт, остальные ветки получают preview-ссылки.
